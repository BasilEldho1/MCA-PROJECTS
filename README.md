The 3D House Floor Plan Designer is a web-based application that helps users design their dream houses and visualize them in 3D.

Normally, architects and designers create house plans using 2D drawings. However, normal 2D drawings are difficult for ordinary people to understand because they cannot clearly visualize the actual appearance of the house.

Our project solves this problem by allowing users to create a 2D floor plan and convert it into a realistic 3D house model.

Users can add rooms, walls, doors, windows, and furniture and view the complete house in an interactive 3D environment.
